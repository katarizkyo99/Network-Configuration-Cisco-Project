# Network Configuration Project

## Overview

A network infrastructure design and configuration project
implemented using Cisco Packet Tracer.

## Network Topology

![Network Topology](./Topology/network-topology.png)

## Key Configurations

- VLAN and switching configuration
- IP addressing
- OSPF routing
- SSH remote access
- DHCP, DNS, Mail, and Web Server
- Access Control List (ACL)
- IPsec VPN
